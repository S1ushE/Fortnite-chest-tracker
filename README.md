# Pirate Token Chest Tracker

A standalone Windows EXE for counting Fortnite pirate token chest openings.

## Features

- Configurable hotkey for counting chests (press-to-set)
- Optional permanent overlay in top-left corner, toggleable by separate hotkey
- Config persistence across sessions (count, hotkeys, overlay visibility)
- Single EXE, no dependencies needed

## Quick Start

1. Download `chest tracker.zip` from the [Releases page](https://github.com/S1ushE/Fortnite-chest-tracker/releases)
2. Run `the EXE file`
3. Press your chest hotkey (default: **E**) to increment the counter
4. Press **O** to toggle the overlay
5. Click **Change** buttons to remap hotkeys
6. Settings auto-save to `config.json` in the same folder as the EXE
